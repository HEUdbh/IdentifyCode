# 验证码识别程序

基于ddddocr开发的图片验证码识别程序，支持用户输入图片地址进行验证码识别。

## 功能特性

- 支持多种图片格式：JPG、JPEG、PNG、BMP、GIF
- 基于ddddocr高精度识别引擎
- 用户友好的交互界面
- 错误处理和输入验证

## 安装依赖

```bash
pip install ddddocr
```

## 使用方法

1. 运行程序：
```bash
python main.py
```

2. 按照提示输入验证码图片的完整路径
3. 程序将显示识别结果
4. 输入 `quit` 退出程序

## 示例

```
=== 验证码识别程序 ===
基于ddddocr开发
支持格式：JPG, JPEG, PNG, BMP, GIF
==============================

请输入验证码图片路径（输入'quit'退出程序）: C:/captcha.png
正在识别图片：C:/captcha.png
识别结果：AB12
```

## 支持的图片格式

- JPG/JPEG
- PNG
- BMP
- GIF

## 注意事项

- 确保输入的图片路径正确
- 图片文件需要具有读取权限
- 程序会自动检查文件格式和存在性
- 支持相对路径和绝对路径

## 错误处理

程序包含完善的错误处理机制，包括：
- 文件不存在检查
- 文件格式验证
- 异常捕获和处理

## 退出程序

输入 `quit` 或使用 Ctrl+C 快捷键退出程序。
